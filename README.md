O Banco agora vai precisa detereminar se os clientes do seu cartão de crédito se tornarão inadimplementes ou não (em ingles Default).

Para tanto, você deve implementar um sistema inteligente que determine se um cliente tem risco e qual é o risco (score) de se tornar inadimplente usando o arquivo de dados default_of_credit_card_clients.

Critérios de avaliação:

Pipeline completo, seleção do melhor modelo, módulo de inferência, resultado acompanhado da distribuição de probabilidade
